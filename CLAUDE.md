## Language and naming

- Commit scopes: `ai`, `api`, `app`, `core`, `engine`, `plugins`, `sdk`, `services`, `ui`. Commits follow Conventional Commits, such as `fix(engine): keep the monitor in sync`.

## The target

Project name: Mikser Studio (formerly codename Nexus), repository Mikser-Studio.
The aim is to create fully fledged AI-backed multimedia studio with extraordinary creative flow never seen to this day.
Creativity with this project needs to be boosted to the limits. We are still following good code standards.
The interface should stay polished and simple with customization in mind (with every sub-window movable and un/dockable like in Adobe Premiere).
Modularity first, main app built around plugins and modules. We had similiar approach in ReflektorTTS.
Use existing open-source project as a source of a know-how and knowledge of what is in use right now.
