# Security
<!-- shared-end -->

Mikser Studio is made to open media files from anywhere, keep keys for AI services, connect to the AI tools you run, and serve a local API that AI agents and other programs on the computer can reach, so security problems in it matter from the first version on. Thank you for reporting them.

<!-- shared-start [github]: the text up to shared-end is the same in every project; change it only where all projects change together. -->
## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub instead: open the repository’s **Security** tab and choose **Report a vulnerability**. Describe what is affected, how to reproduce it, and what an attacker could do with it.
<!-- shared-end -->

<!-- shared-start: the text up to shared-end is the same in every project; change it only where all projects change together. -->
## Supported versions

Only the latest release is supported: fixes go into the `main` branch and the next release. Before the first release, fixes go into `main`.
